# Afbeeldingen / Images

Deze map bevat de visuele assets van de website. In deze demoversie zijn het
**placeholders** (SVG-illustraties) zodat het ontwerp compleet oogt zonder
definitieve fotografie.

## Vervangen door echte foto's

1. Plaats je afbeelding (bij voorkeur `.webp` of `.avif`, geoptimaliseerd) in deze map.
2. Vervang het bestand met dezelfde naam, of pas het `src`-pad aan in de component.
3. Zorg voor een beschrijvende `alt`-tekst in de component (niet voor puur decoratieve beelden).

## Aanbevolen onderwerpen

- Een moderne lesauto van de rijschool
- Nederlandse straten en verkeerssituaties
- Een leerling met de instructeur
- Details uit de auto (dashboard, stuur)
- Wegmarkeringen en verkeersinfrastructuur

## Huidige placeholders

| Bestand                 | Gebruikt op | Aanbevolen echte foto              |
| ----------------------- | ----------- | ---------------------------------- |
| `instructeur.svg`       | Over ons    | Portret van de instructeur / auto  |
| `lesauto.svg`           | Over ons    | De lesauto op een Nederlandse weg  |

> Aanbevolen formaat voor foto's: minimaal 1200px breed, 4:5 of 3:2 ratio.
